Know your tier.

Tiers describe how a data center's power and cooling infrastructure handles maintenance and failure. Explore the four levels, then train your team on what it takes to run each one.

I

Basic capacity

A single path for power and cooling and no redundant components. Planned maintenance means shutting down.

Single path · N

II

Redundant capacity components

Redundant components (such as extra UPS modules, chillers or generators) on a single distribution path. Some component maintenance without shutdown, but the path is still a single point of failure.

Single path · N+1

III

Concurrently maintainable

Multiple distribution paths, with one active at a time. Every component and path can be taken out for planned maintenance without shutting down IT equipment.

Multiple paths · N+1

IV

Fault tolerant

Multiple independent, physically isolated, active paths. A single failure of any component or path doesn't affect IT equipment, and the site can be maintained concurrently.

2N or 2(N+1) · compartmentalized
